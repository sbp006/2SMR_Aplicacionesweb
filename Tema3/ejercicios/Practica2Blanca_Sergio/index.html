¿Quiénes somos?

Somos un grupo de alumnos y alumnas de Sistemas Microinformáticos y Redes que se reúne una tarde a la semana para aprender cosas que no siempre caben en el horario de clase: montar equipos, configurar redes, instalar servidores y crear páginas web.

No hace falta saber nada para empezar. Solo traer ganas de aprender y, si puedes, tu propio portátil.

¿Qué hacemos?

  • Montaje y reparación de ordenadores
  • Configuración de routers y redes domésticas
  • Instalación de sistemas operativos
  • Creación de páginas web con HTML y CSS
  • Torneos de videojuegos en red local

Cómo apuntarte

  1. Lee las actividades del trimestre.
  2. Rellena el formulario de inscripción.
  3. Espera el correo de confirmación.
  4. Ven el primer día al aula de informática.
